## 5. Bloqueios e Decisões

- **Decisão:** JSONL como formato de histórico (em vez de JSON ou SQLite) — append-only, append barato, legível por humanos, não requer schema rígido
- **Decisão:** Versionamento pré-save: arquivo existente é renomeado para `{stem}_v{n}{suffix}` ANTES de salvar a nova versão, garantindo que o arquivo principal sempre aponte para a versão mais recente
- **Decisão:** `read_generation_history` tolerante a linhas corrompidas (pula `JSONDecodeError`) e retorna lista vazia se JSONL não existir — operações de consulta nunca quebram
- **Decisão:** `get_history` no `MCPDocumentService` silencia exceções (retorna `[]`) para manter contrato da camada MCP
- **Decisão:** TUI `history_documents_ui` lê JSONL diretamente (sem passar pelo `DocumentService`) para evitar sobrecarga de criação de service — padrão consistente com outras UIs no mesmo arquivo

## 6. Contexto da Conversa (Resumo para Próximo Agente)
