## 4. Detalhamento Técnico

### `rag_schema.py`
- **RAG_SCHEMA**: JSON Schema Draft 7 — `embedding_mode` (enum minilm/bgem3/dual), `pipeline.type` (enum simple/rerank), `pipeline.nodes` (array string), `models.primary` (string), `models.fallback` (array string)
- **`_KNOWN_KEYS`**: chaves conhecidas são propagadas; desconhecidas são removidas com warning (forward compat)
- **`validate_rag_config(raw)`**: 
  - raw vazio/nulo → `DEFAULT_RAG_CONFIG`
  - válido → deep merge campos válidos sobre defaults
  - inválido → log warning por erro + fallback field-by-field
  - unknown keys → log warning + removidas do resultado

### `config.py` (mudanças)
- Import `validate_rag_config` no topo
- `_rag_validated` inicializado em `_load_settings()` após `_validate_settings()`
- 4 novas properties tipadas:
  - `rag_embedding_mode → str`
  - `rag_pipeline_type → str`
  - `rag_models_primary → str`
  - `rag_models_fallback → List[str]`
- `rag_config` legacy property mantida (backward compat)
