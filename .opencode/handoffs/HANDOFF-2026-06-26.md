## 6. Decisões Técnicas

- **`add_entry()` mantém assinatura legada** + `entry=` kwarg opcional em vez de quebrar chamadas existentes
- **`create_client()` retorna `Client` entity** (ACE) — exige que callers usem `str(client.codigo)` para string e obtenham path via `Config.base_pasta_clientes / client.nome`
- **Código normalizado em 3 etapas:** `generate_client_code()` → `unicodedata.normalize('NFKD')` (remove acentos) → `re.sub(r'[^A-Z0-9]', '', ...)` → fallback `base + "01"` se não encaixar no pattern
- **`ClientCode` pattern:** `^[A-Z]{3,5}[0-9]{2}$` — rejeita códigos como "MINI" (sem dígitos)
- **`generate_client_code` NÃO foi alterado** — códigos legados "MINI" são aceitos via `try/except` em `Client.from_row()`
