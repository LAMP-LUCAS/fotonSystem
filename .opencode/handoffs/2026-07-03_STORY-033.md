## 4. Bloqueios e Decisões
- **Decisões:**
  - `ProcessContext` extende `MutableMapping` com validação de chaves — permite `setdefault()` para chaves dinâmicas
  - `EmbedNode` itera `VectorStoreManager.active_tags` chamando `instance.embed_query()` (adicionado ao VectorStoreInstance)
  - `SearchNode` usa `query_with_embeddings()` (via embeddings do contexto) caindo para `query()` se embedding ausente
  - `RerankNode` usa lazy import de `CrossEncoder` via `_check_cross_encoder()` para evitar slow import na carga do módulo (CrossEncoder leva ~14s)
  - Pipeline "rerank" com fallback: se CrossEncoder não disponível, nó rerank é omitido silenciosamente
  - `RagPipeline.from_config()` lê `Config().rag_config["pipeline"]` — compatível com SPEC-RAG-v2.0
  - Pipeline customizado (RULE-RAG-11.6) preparado: `RagPipeline` aceita `nodes: List[str]` arbitrário
